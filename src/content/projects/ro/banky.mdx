## Cum funcționează

Modelul de limbaj face singurul lucru pe care codul nu îl poate face: transformă o pagină dezordonată în rânduri
structurate. Tot ce este înainte și după el este determinist. Modelul rulează într-o rețea izolată, fără acces la
internet.

Observațiile scrise trec prin cinci etape (ciornă, verificare, critică, revizuire, verificare), iar ultimul cuvânt îl
are o verificare fixă, bazată pe reguli. Pe o placă de 24 GB, mai multe treceri ale unui model care încape în memorie
sunt mai bune decât o singură trecere a unuia mai mare.

## Verificarea, în cod

<CodeSnippet
  file="backend/app/ai/extraction_guard.py"
  lang="python"
  caption="Fiecare număr din rezultatul modelului trebuie să fie identic cu un număr care a fost citit. Nu ajunge o potrivire parțială: exact așa ar trece neobservată o primă cifră omisă."
  code={`
_DIGITS = re.compile(r"\\D")
_DIGIT_RUN = re.compile(r"\\d[\\d.,]*\\d|\\d")


def digits(text: str) -> str:
    return _DIGITS.sub("", text or "")


def is_grounded(value: str, sources: list[str]) -> bool:
    if not value:
        return True

    source_runs = [digits(run) for block in sources for run in _DIGIT_RUN.findall(block)]
    for run in _DIGIT_RUN.findall(value):
        needle = digits(run)
        if not needle:
            continue
        if needle not in source_runs:
            return False
    return True
`}
