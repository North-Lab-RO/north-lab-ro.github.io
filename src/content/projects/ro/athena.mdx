inteligența artificială ajută, dar nu hotărăște ce e adevărat.

## Sursele își câștigă încrederea

Asistentul vede cât de sigură s-a dovedit fiecare sursă în cazul respectiv: ce parte din constatările ei au fost
confirmate de analiști. O sursă respinsă des contează mai puțin în răspuns.

<CodeSnippet
  file="backend/apps/ai/services.py"
  lang="python"
  caption="Deciziile de confirmare și respingere devin, pentru fiecare sursă, un indice de acuratețe de care AI-ul ține cont."
  code={`
def _compute_source_accuracy(case) -> dict[str, dict]:
    rows = (
        Evidence.objects
        .filter(case=case)
        .exclude(status="pending")
        .values("source_name", "source_type")
        .annotate(
            total=Count("id"),
            confirmed=Count("id", filter=Q(status="confirmed")),
            rejected=Count("id", filter=Q(status="rejected")),
        )
    )
    out: dict[str, dict] = {}
    for r in rows:
        key = (r["source_name"] or r["source_type"]).strip()
        if not key or r["total"] == 0:
            continue
        ratio = r["confirmed"] / r["total"] if r["total"] else 0.0
        out[key] = {
            "confirmed": r["confirmed"],
            "rejected": r["rejected"],
            "total": r["total"],
            "ratio": round(ratio, 2),
        }
    return out
`}
