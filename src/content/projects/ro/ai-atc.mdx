## Cum funcționează

Un răspuns radio are la dispoziție două până la patru secunde, așa că fiecare etapă e măsurată. Whisper tiny.en a
fost ales după ce aceeași transmisie a fost testată cu mai multe dimensiuni de model: toate au înțeles la fel de bine
intenția pilotului, iar tiny e de 20 de ori mai rapid decât medium.

## Alegerea controlorului după faza de zbor

Când frecvența și cuvintele-cheie nu sunt de ajuns, sistemul se uită la faza de zbor, apoi la faptul că avionul e la
sol sau în aer și la altitudine.

<CodeSnippet
  file="fastapi/agents/router.py"
  lang="python"
  caption="Ultima variantă din lanțul de decizie. Înainte de ea contează controlorul care are avionul în grijă, frecvența pe care e acordată stația și cuvintele-cheie explicite."
  code={`
phase = aircraft_state.get("phase", "cruise").lower()
possible_agents = self.phase_agent_map.get(phase, ["center"])

if len(possible_agents) > 1:
    altitude = aircraft_state.get("altitude_msl", 0)
    on_ground = aircraft_state.get("on_ground", False)

    if on_ground:
        if "clearance" in possible_agents:
            return "clearance"
        return "ground"
    elif altitude < 18000:
        if "approach" in possible_agents:
            return "approach"
        return "tower"
    else:
        if "center" in possible_agents:
            return "center"

return possible_agents[0]
`}
/>
