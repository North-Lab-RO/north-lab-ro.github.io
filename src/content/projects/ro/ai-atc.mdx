## Cum funcționează

Un răspuns radio are la dispoziție două până la patru secunde, așa că fiecare etapă este măsurată. Whisper tiny.en a
fost ales după testarea aceleiași transmisii cu mai multe dimensiuni de model: toate patru au înțeles intenția la fel
de bine, iar tiny este de 20 de ori mai rapid decât medium.

## Alegerea după faza de zbor

Când frecvența și cuvintele cheie nu sunt suficiente, routerul se bazează pe faza de zbor, apoi pe faptul că aeronava
este la sol sau în aer și pe altitudinea ei.

<CodeSnippet
  file="fastapi/agents/router.py"
  lang="python"
  caption="Ultima variantă din lanțul de alegere. Verificările anterioare folosesc controlorul care are aeronava în grijă, frecvența selectată și cuvintele cheie explicite."
  code={`
phase = aircraft_state.get("phase", "cruise").lower()
possible_agents = self.phase_agent_map.get(phase, ["center"])

if len(possible_agents) > 1:
    altitude = aircraft_state.get("altitude_msl", 0)
    on_ground = aircraft_state.get("on_ground", False)

    if on_ground:
        if "clearance" in possible_agents:
            return "clearance"
        return "ground"
    elif altitude < 18000:
        if "approach" in possible_agents:
            return "approach"
        return "tower"
    else:
        if "center" in possible_agents:
            return "center"

return possible_agents[0]
`}
/>
