## Cum funcționează

Patru etape transformă un flux de titluri în câteva povești care merită citite. Derulează mai jos pentru a le vedea.

<CounselorStory lang="ro" />

În spate, munca rulează ca sarcini în patru cozi separate, astfel încât procesarea în masă a articolelor nu blochează
niciodată analiza poveștilor importante. Două modele își împart efortul: unul mic se ocupă de fiecare articol, iar
unul mai mare rulează doar acolo unde se întâlnesc multe surse.

## Verdictele sunt calculate, nu generate

Un model lăsat liber să răspundă „confirmat” poate face asta fără să citeze nimic. COUNSELOR caută citate din *alte*
publicații și îi cere modelului doar să le clasifice. Verdictul rezultă apoi din numărătoare.

<CodeSnippet
  file="backend/app/services/fact_check.py"
  lang="python"
  caption="Articolul care face afirmația și publicația lui nu o pot confirma niciodată, iar un citat dintr-o sursă necunoscută este eliminat, nu atribuit unui nume ghicit."
  code={`
def gather_evidence(
    hits: list[SearchHit],
    *,
    claim_article_id: int | None,
    claim_source_id: int | None,
    source_names: dict[int, str],
) -> list[Evidence]:
    best: dict[int, Evidence] = {}
    for h in hits:
        payload = h.payload or {}
        source_id = payload.get("source_id")
        article_id = payload.get("article_id")
        text = (payload.get("text") or "").strip()
        if not text or source_id is None:
            continue
        if article_id is not None and article_id == claim_article_id:
            continue
        if source_id == claim_source_id:
            continue
        name = source_names.get(source_id)
        if not name:
            continue
        ...
    return sorted(best.values(), key=lambda e: e.score, reverse=True)


def decide_verdict(*, supporting: int, contradicting: int) -> str:
    if contradicting > 0:
        return CONTESTED
    if supporting >= 2:
        return CONFIRMED
    if supporting == 1:
        return SINGLE_SOURCE
    return UNVERIFIABLE
`}
/>
