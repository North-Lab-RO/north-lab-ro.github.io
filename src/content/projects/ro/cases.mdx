## Cum funcționează

Modelul de limbaj și cel de imagine nu încap simultan pe o placă de 24 GB, așa că un mecanism de rezervare a GPU-ului
le rulează pe rând. Totul este generat dinainte, deci jocul propriu-zis nu are nevoie deloc de GPU.

## Rezolvabilitatea este o demonstrație, nu o speranță

Fiecare acțiune pe care o poate face echipa (o percheziție, un interogatoriu, un test de laborator, o cerere de
documente) are condiții, dezvăluiri și un cost în timp. Validatorul calculează tot ce poate fi aflat pornind de la
informațiile inițiale, apoi verifică dacă cel mai scurt drum spre probele decisive încape în timpul disponibil.

  file="packages/shared/src/knowledge.ts"

  caption="O închidere de tip punct fix peste acțiunile cazului. Orice probă decisivă rămasă în afara ei trimite cazul înapoi la etapa care o poate produce."
  code={`
export function computeClosure(
  initial: readonly KnowledgeKey[],
  actions: readonly DiscoveryAction[],
): Set<KnowledgeKey> {
  const held = new Set<KnowledgeKey>(initial);
  let grew = true;
  while (grew) {
    grew = false;
    for (const act of actions) {
      if (!isSatisfied(held, act.requires)) continue;
      for (const key of act.reveals) {
        if (!held.has(key)) {
          held.add(key);
          grew = true;
        }
      }
    }
  }
  return held;
}

// validation/solvability.ts
const closure = computeClosure(initial, actions);
const unreachable = draft.truth.provingEvidence.filter((key) => !closure.has(key));

const path = computeCriticalPath(initial, actions, draft.truth.provingEvidence);
const budgetSeconds = draft.profile.timeBudgetMinutes * 60;
const fraction = path.costSeconds / budgetSeconds;
if (fraction > draft.profile.maxCriticalPathFraction) {
  const used = Math.round(fraction * 100);
  const allowed = Math.round(draft.profile.maxCriticalPathFraction * 100);
  issues.push(issue(7,
    \`Critical path costs \${used}% of the time budget, above the \${allowed}% ceiling.\`));
}
`}
