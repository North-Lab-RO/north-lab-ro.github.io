## How it works

The pipeline runs as queued jobs on four separate queues, so bulk article work never blocks the high-value story
analysis. Two models split the load: a small one handles every article, and a larger one runs only where many sources
meet.

## Verdicts are computed, not generated

A model that is free to answer "confirmed" can do so while citing nothing. COUNSELOR retrieves quotes from *other*
outlets and asks the model only to classify each one. The verdict then follows from the tallies.

<CodeSnippet

  lang="python"
  caption="A claim's own article and its own outlet can never corroborate it, and a quote from an unknown source is dropped rather than cited under a guessed name."
  code={`
def gather_evidence(
    hits: list[SearchHit],
    *,
    claim_article_id: int | None,
    claim_source_id: int | None,
    source_names: dict[int, str],
) -> list[Evidence]:
    best: dict[int, Evidence] = {}
    for h in hits:
        payload = h.payload or {}
        source_id = payload.get("source_id")
        article_id = payload.get("article_id")
        text = (payload.get("text") or "").strip()
        if not text or source_id is None:
            continue
        if article_id is not None and article_id == claim_article_id:
            continue
        if source_id == claim_source_id:
            continue
        name = source_names.get(source_id)
        if not name:
            continue
        ...
    return sorted(best.values(), key=lambda e: e.score, reverse=True)


def decide_verdict(*, supporting: int, contradicting: int) -> str:
    if contradicting > 0:
        return CONTESTED
    if supporting >= 2:
        return CONFIRMED
    if supporting == 1:
        return SINGLE_SOURCE
    return UNVERIFIABLE
