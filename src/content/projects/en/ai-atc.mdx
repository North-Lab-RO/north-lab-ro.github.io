## How it works

A radio reply has a two-to-four-second budget, so every stage is measured. Whisper tiny.en was chosen after
benchmarking the same transmission across model sizes: all four produced the same intent accuracy, and tiny is 20×
faster than medium.

## Routing by flight phase

When the frequency and keywords don't settle it, the router falls back to the flight phase, then to whether the
aircraft is on the ground and how high it is.

<CodeSnippet
  file="fastapi/agents/router.py"
  lang="python"
  caption="The last fallback in the routing chain. Earlier checks use the controller that owns the aircraft, the tuned frequency and explicit keywords."
  code={`
phase = aircraft_state.get("phase", "cruise").lower()
possible_agents = self.phase_agent_map.get(phase, ["center"])

if len(possible_agents) > 1:
    altitude = aircraft_state.get("altitude_msl", 0)
    on_ground = aircraft_state.get("on_ground", False)

    if on_ground:
        if "clearance" in possible_agents:
            return "clearance"
        return "ground"
    elif altitude < 18000:
        if "approach" in possible_agents:
            return "approach"
        return "tower"
    else:
        if "center" in possible_agents:
            return "center"

return possible_agents[0]
`}
