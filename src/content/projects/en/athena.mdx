## How it works

A case moves from leads to evidence to a report. Collection is automated; judgement stays with the analyst; the AI
helps but never decides what is true.

## Sources earn their weight

The assistant sees how reliable each source has been in this case: the share of its findings that analysts
confirmed. A source that keeps being rejected carries less weight in the answer.

<Flow
  title="How a source earns trust"
  caption="Analysts decide what is true; the assistant learns which sources to rely on."
  nodes={[
    {
      "label": "A collector reports a finding",
      "detail": "From web search, DNS and WHOIS, social profiles, images and the other collectors."
    },
    {
      "kind": "decision",
      "label": "An analyst reviews it",
      "branches": [
        {
          "when": "Pending",
          "then": "Not counted yet.",
          "tone": "neutral"
        },
        {
          "when": "Rejected",
          "then": "Counts against the source, and never reaches the report.",
          "tone": "bad"
        }
      ],
      "yes": "Confirmed"
    },
    {
      "label": "Each source gets a track record",
      "detail": "Confirmed findings out of all reviewed findings, per source, for this case."
    },
    {
      "kind": "decision",
      "label": "When the assistant answers",
      "branches": [
        {
          "when": "Reliable source",
          "then": "Given more weight.",
          "tone": "ok"

        {
          "when": "Often rejected",

## Reports that fit the subject

The structured report adapts to what the case is about: a report on a person drops the infrastructure section, and
any section without data is left out rather than filled with padding.
