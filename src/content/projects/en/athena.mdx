## How it works

A case moves from leads to evidence to a report. Collection is automated; judgement stays with the analyst; the AI
helps but never decides what is true.

## Sources earn their weight

The assistant sees how reliable each source has been in this case: the share of its findings that analysts
confirmed. A source that keeps being rejected carries less weight in the answer.

<CodeSnippet
  file="backend/apps/ai/services.py"
  lang="python"
  caption="Confirm and reject decisions become a per-source accuracy ratio that the AI takes into account."
  code={`
def _compute_source_accuracy(case) -> dict[str, dict]:
    rows = (
        Evidence.objects
        .filter(case=case)
        .exclude(status="pending")
        .values("source_name", "source_type")
        .annotate(
            total=Count("id"),
            confirmed=Count("id", filter=Q(status="confirmed")),
            rejected=Count("id", filter=Q(status="rejected")),
        )
    )
    out: dict[str, dict] = {}
    for r in rows:
        key = (r["source_name"] or r["source_type"]).strip()
        if not key or r["total"] == 0:
            continue
        ratio = r["confirmed"] / r["total"] if r["total"] else 0.0
        out[key] = {
            "confirmed": r["confirmed"],
            "rejected": r["rejected"],
            "total": r["total"],
            "ratio": round(ratio, 2),
        }
    return out
`}

## Reports that fit the subject

The structured report adapts to what the case is about: a report on a person drops the infrastructure section, and
any section without data is left out rather than filled with padding.

<CodeSnippet
  file="backend/apps/reports/structured.py"
  lang="python"
  caption="Sections are built from the case data, then only the non-empty ones are kept, in the standard order."
  code={`
evidence = list(
    Evidence.objects.filter(case=case).exclude(status="rejected").order_by("-created_at")
)
profile = detect_profile(entities, selectors)

infrastructure = _build_infrastructure(selectors, evidence)
digital = _build_digital_footprint(selectors, evidence)
network = _build_relationships(relationships)
timeline = _build_timeline(case, evidence)

    infrastructure = ""

sections = [
    {"title": title, "markdown": md}
    for title, md in candidates
    if md and md.strip()
]
`}
