## Engineering notes

Statements that contain text, and spreadsheets, are read by layout rules written for each bank, with no AI. The
language model does the one thing rules can't: turning the text read from a scanned page or a receipt photo into
structured rows, and every number it returns must match the page. The model and the OCR run on an isolated network
with no internet access.

Written insights take five passes (draft, verify, critique, revise, verify), and a fixed rule-based guard has the final
say. On a 24 GB card, several passes of a model that fits in memory beat a single pass of a larger one.
