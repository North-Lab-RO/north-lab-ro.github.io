## How it works

The language model does the one thing code can't: turning a messy page into structured rows. Everything before and
after it is deterministic. The model runs on an isolated network with no internet access.

Written insights take five passes (draft, verify, critique, revise, verify), and a fixed rule-based guard has the final
say. On a 24 GB card, several passes of a model that fits in memory beat a single pass of a larger one.

## The guard, in code

<CodeSnippet
  file="backend/app/ai/extraction_guard.py"
  lang="python"
  caption="Each numeral in the model's output must equal a numeral that was read. Substring matches are not enough: that is exactly how a dropped leading digit would slip through."
  code={`
_DIGITS = re.compile(r"\\D")
_DIGIT_RUN = re.compile(r"\\d[\\d.,]*\\d|\\d")


def digits(text: str) -> str:
    return _DIGITS.sub("", text or "")


def is_grounded(value: str, sources: list[str]) -> bool:
    if not value:
        return True

    source_runs = [digits(run) for block in sources for run in _DIGIT_RUN.findall(block)]
    for run in _DIGIT_RUN.findall(value):
        needle = digits(run)
        if not needle:
            continue
        if needle not in source_runs:
            return False
    return True
`}
